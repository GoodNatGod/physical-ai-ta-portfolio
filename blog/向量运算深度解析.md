## <a id="1"></a>1. 向量加法 —— 平行四边形法则

**一句话**：两个向量相加，等于把它们的"箭头"首尾相接，从起点到终点的新箭头。

### 代码验证

```
风力  = [1, 0, 0]      （沿X轴吹，1牛顿）
重力  = [0, -9.8, 0]    （向下，9.8牛顿）
合力  = [1, -9.8, 0]    （斜着向下）
```

### 几何理解

以两个向量为邻边画平行四边形，对角线就是和向量。

### 物理意义

- 任何"叠加"都是向量加法：合力、合速度、合加速度
- **物理引擎每帧都在做这件事**：物体的加速度 = 重力 + 风力 + 推力 + 碰撞冲量，全部是向量相加

### 关键直觉

向量加法**遵守交换律**（a+b = b+a），因为力的先后叠加不影响结果。这个性质在后面矩阵那里就不成立了——记住这个对比。

## <a id="2"></a>2. 标量乘法 —— 缩放与反向

**一句话**：用一个数字乘以向量，等于把箭头拉长/缩短/翻转，方向不变（除非是负数）。

### 代码验证

```
2 × [1,0,0]  = [2,0,0]     （力变成2倍）
-1 × [1,0,0] = [-1,0,0]    （力反向）
```

### 物理意义

- 弹簧力 `F = -k·x`：位移 x 乘以系数 -k，负号表示"反向拉回"
- 阻尼力 `F = -c·v`：速度乘以负系数
- 加速度 `a = (1/m)·F`：力除以质量

> 这是所有**线性力模型**的基础。物理仿真里大量公式长这样——本质就是标量乘法。

## <a id="3"></a>3. 点积 —— 投影 / 做功 / 夹角

这是**最有深度**的一个运算。有两种等价理解：

### 理解A：代数定义
```
a·b = a₁b₁ + a₂b₂ + a₃b₃
```

### 理解B：几何定义（更关键）
```
a·b = |a| × |b| × cosθ
```

即：**a的模长 × b在a方向上的投影长度**。

这两个定义等价，但理解B才是灵魂。

### 物理意义1：做功

```
W = F·d = |F| × |d| × cosθ
```

只有"力在位移方向上的分量"才做功：

- 力和位移同向 → 做功最大（50J）
- 力和位移垂直 → 做功为0（垂直力不推动物体）

### 物理意义2：判断夹角（仿真里最常用的用途）

```
cosθ = (a·b) / (|a|×|b|)
```

| 点积值 | 夹角 | 含义 |
|---|---|---|
| > 0 | < 90° | 两向量"大致同向" |
| = 0 | = 90° | 正交，垂直 |
| < 0 | > 90° | "大致反向" |

### 为什么对物理AI重要

- **碰撞检测**：用点积判断两个表面法线是否相对（正向碰撞 vs 分离）
- **视线/朝向**：相机前方向量与物体方向的点积 > 0 才"看得到"
- **布料/软体**：相邻三角形法线点积 < 0 表示折痕

> 💡 一句话记住：**点积是"同向程度"的量化器**。

## <a id="4"></a>4. 叉积 —— 力矩 / 法线 / 面积

叉积比点积更"反直觉"，因为它**结果还是个向量**（不在原平面内）。

### 代数定义
```
a×b = [a₂b₃-a₃b₂, a₃b₁-a₁b₃, a₁b₂-a₂b₁]
```

### 几何意义（灵魂）

```
|a×b| = |a| × |b| × sinθ
```

- 结果向量的**模长** = 两向量围成的**平行四边形面积**
- 结果向量的**方向** = 垂直于 a 和 b 所在的平面

### 物理意义1：力矩

```
τ = r × F
```

- `r` = 从转轴到作用点的向量（力臂）
- `F` = 力
- 力矩方向 = 旋转轴方向（用右手定则确定转哪边）

代码结果：力臂 `[1,0,0]` × 力 `[0,0,10]` = 力矩 `[0,-10,0]`

> 刚体动力学里，所有旋转都是靠"力矩 → 角加速度"驱动的。角速度、角加速度都是向量（有方向），叉积是把"线性的力"转成"旋转的矩"的桥梁。

### 物理意义2：表面法线

```
法线 = edge1 × edge2
```

三角形两条边叉乘，得到的就是垂直于三角形表面的向量。

### 为什么对物理AI致命重要

| 场景 | 叉积的作用 |
|---|---|
| 碰撞检测 (GJK) | 支撑函数需要法线方向来搜索最近点 |
| 光照渲染 | `diffuse = dot(normal, lightDir)`，法线直接决定明暗 |
| 接触约束 | 两个物体接触时，接触法线决定了冲量方向 |

> 💡 一句话记住：**叉积生成"垂直于原平面的新向量"，模长是面积**。

## <a id="5"></a>5. 右手定则 —— 叉积方向的确定

叉积结果**朝哪边**？必须统一规则，否则仿真会崩。

### 操作

右手四指从 a 弯向 b，大拇指指向就是 a×b 的方向。

### 代码验证

```
X × Y = Z       （不是 -Z！）
Y × X = -Z      （反过来了）
Y × Z = X       （验证轮换性）
Z × X = Y
```

### 反交换律：a×b = -(b×a)

这是叉积和点积最本质的区别：

| 运算 | 交换律 | 说明 |
|---|---|---|
| 点积 | a·b = b·a | 标量，无方向问题 |
| 叉积 | a×b = **-b·a** | 顺序颠倒，结果反向！ |

### 为什么致命重要

- 物理引擎里如果"力矩 = F×r"写成了"r×F"，旋转方向会反
- 法线方向反了，光照会"内外翻转"，碰撞会判断成"穿透"

> 💡 一句话记住：**叉积的顺序 = 方向**，写反了整个物理就反了。

## <a id="6"></a>6. 串联：为什么这四个运算撑起了物理仿真

物理引擎的每一帧都在重复这几个操作几百万次：

| 运算 | 在物理引擎哪里用 |
|---|---|
| **向量加法** | 每帧合力 = 重力+推力+碰撞冲量 |
| **标量乘法** | 加速度 = 力/质量 |
| **点积** | 判断碰撞法线相对、计算做功、光照 |
| **叉积** | 力矩驱动旋转、求表面法线、GJK支撑函数 |

### 前瞻

Phase 2 你要手写 GJK 碰撞检测时，点积和叉积会直接出现在核心循环里：

```python
# GJK 核心循环（Phase 2 你会写这个）
while True:
    # 点积：判断是否穿过原点
    # 叉积：构建搜索方向
    # 向量加法：更新单纯形
    # 标量乘法：缩放支撑向量
```
